Privacy

What this app stores

Your job board data is stored in this browser using localStorage. The app does not send your cards to an app-controlled server, and it does not use cookies.

Import and export files stay local to your device unless you choose to move them elsewhere. The page also avoids unnecessary external requests by using self-hosted assets from this repository.

If you host this page yourself, normal web hosting and browser request metadata may still exist, such as IP address, user-agent, or server logs. That metadata is separate from the card data you enter into the board.
